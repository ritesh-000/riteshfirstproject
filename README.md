# 🌍 WanderLust Project

A full-stack web application where users can explore, create, and review travel listings.

## 🚀 Live Demo

https://riteshfirstproject-2.onrender.com
after click Explore icon


## 📌 Features
- 🔐 User Authentication (Login/Signup)
- 🏠 Create, Edit, Delete Listings
- ⭐ Add Reviews & Ratings
- 🖼️ Image Upload using Cloudinary
- 🗺️ Location Map using Mapbox
- 📱 Responsive UI

## 🛠️ Tech Stack

### Frontend:
- HTML
- CSS
- JavaScript
- EJS

### Backend:
- Node.js
- Express.js

### Database:
- MongoDB (MongoDB Atlas)

### Other Tools:
- Cloudinary (Image Upload)
- Mapbox (Maps & Location)
- Git & GitHub (Version Control)
- Render (Deployment)
